      What is disposable email?
      
          
      
            A disposable email address gives you a temporary inbox for one-off registrations, receipts, and download links without sharing your personal mailbox.
          
      
          
      
            Once the countdown expires, the address and every message delivered to it are permanently erased from memory. Nothing is archived, forwarded, or linked to an account.

      Frequently asked questions
      
      
      
        
      
          How long does an email address stay active?
          
      Each address remains active until its countdown reaches zero. You can click "Add time" at any point before expiry to reset the timer.
      
        
      
        
      
          Can I send emails from this address?
          
      Yes. Click “Compose” (or call POST /api/v1/inbox/:address/send) to send email from your active address. Delivery works immediately between local own-server addresses, between @mailto.plus / @fexpost.com public addresses, and externally over direct MX or an optional SMTP relay.
      
        
      
        
      
          Are attachments stored on the server?
          
      No. Attachment file contents are discarded at delivery. Only the filename, content type, and file size metadata are displayed.
      
        
      
        
      
          Why are images hidden when I open an email?
          
      Senders often embed remote tracking pixels in HTML emails. Remote images stay blocked until you explicitly choose "Load images".
      
        
      
        
      
          Can someone else read my inbox?
          
      Access requires a secret token issued once to your browser when the inbox is created. Without that token, the server returns 404.
      
        
      
      
      
    
      

    
      
      
      Privacy
      
      
      
        All active inboxes and messages are stored in memory only until their expiration timestamp is reached, at which point Redis automatically purges the keys.
        Throwaway does not write incoming emails to long-term disk databases, does not store attachment payloads, strips unsafe HTML tags and scripts before storage, and blocks external image requests by default inside a sandboxed viewer.
